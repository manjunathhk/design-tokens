Shipping one palette to every site

Each site links one stylesheet. A change to a token reaches every site on the next release, and semantic versioning keeps breaking changes out.

How a release works

  1. Merge the change into main.
  2. Push a tag such as v1.5.0.
  3. The workflow uploads, publishes and verifies.

What sites receive

  • Every new token and value change on /v1/.
  • Nothing that renames or removes a token.

Change once, reflect everywhere.

Forcing a theme

Press Ctrl + Shift + L, or set it in markup:

<html data-theme="dark">
