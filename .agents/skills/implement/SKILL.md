Find the issue number in the user's request (for example the `<n>` in
"implement issue #<n>" or "/implement issue <n>"). Then implement that issue
by following `docs/workflow/implement-issue.md` exactly. That file is the
single source of the procedure; do not work from memory of it.

If no issue number is present in the request, ask for one instead of
guessing.
